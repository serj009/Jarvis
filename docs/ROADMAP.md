## 1. Как работать в двух местах

| | Дом | Работа |
|---|---|---|
| Что есть | Полная среда: GPU RTX 3060, Ollama + `qwen3:8b`, микрофон, модели STT/TTS/wake word | Только код и тесты |
| Что делать | Живые проверки голосом, чтение логов, замеры, настройка порогов | Код, юнит-тесты, рефакторинг, документация |
| Как понять, что готово | Поведение в логе живой сессии | `ruff`, `pyright` и `pytest` зелёные |

Каждая задача помечена:

- **[Работа]** — можно сделать и проверить тестами без домашнего ПК;
- **[Дом]** — нужен живой запуск Jarvis;
- **[Работа → Дом]** — код пишется на работе, финальная проверка голосом дома.

### Цикл

1. **Работа:** `git pull`, взять задачу из текущего этапа, написать код и тест, прогнать проверки, `git push`.
2. **Дом:** `git pull`, запустить Jarvis с дампом запросов, проговорить фразы из раздела 6, закрыть Jarvis.
3. **Дом:** попросить Claude «проверь логи» (или прочитать самому — таблица «Где логи»).
4. Обновить этот файл: закрытое удалить, новые находки — в бэклог. Вопрос, который может решить только владелец, — в бэклог с пометкой «нужно решение»; пока решения нет, по задаче не работать.

### Работа из браузера (облачная сессия Claude Code)

Без установки на рабочем ПК: claude.ai/code → репозиторий `serj009/Jarvis`, ветка `amazonq`. Claude работает в облачной копии репозитория (Linux): правит код, гоняет `ruff` / `pyright` / `pytest` и пушит в ветку. Живого Jarvis там нет (ни GPU, ни Ollama, ни микрофона, ни твоих данных), поэтому брать задачи **[Работа]**; у **[Работа → Дом]** — только кодовую часть. Тесты на Linux: платформенные (Windows) там пропускаются или не запускаются — финальный прогон всё равно дома на Windows. Дома: `git pull` и цикл выше (шаги 2–4).

### Среда на работе (один раз)

```powershell
git clone https://github.com/serj009/Jarvis.git
cd Jarvis
git checkout amazonq
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```

Python 3.14, как дома. Модели и Ollama для тестов не нужны: тяжёлое замокано, тесты `manual` и `slow` по умолчанию пропускаются.

Не держи на рабочем ПК личные файлы: `my_preferences.yaml`, образцы голосов, базы памяти. В git их нет и не должно быть.

### Проверки перед пушем

```powershell
.venv\Scripts\python.exe -m ruff check jarvis tests
.venv\Scripts\python.exe -m pyright <изменённые файлы>
.venv\Scripts\python.exe -m pytest -q
```

Эталон на 2026-11-03: **6766 passed, 14 skipped, 10 deselected**, около 3 минут. В CI (`.github/workflows/ci.yml`, Windows и Ubuntu) обязательны все три проверки. В `jarvis/` есть старые ошибки pyright (задача M2-1) — проверяй pyright только по своим файлам.

### Запуск дома

Только из `.venv`. Глобальный `python` падает: в его site-packages нет модели wake word.

```powershell
$env:JARVIS_DUMP_LLM_REQUEST = "1"; .venv\Scripts\python.exe -m jarvis
```

### Где логи

| Файл | Что внутри |
|---|---|
| `%APPDATA%\Jarvis\logs\jarvis.log.jsonl` | Структурированный лог, время в UTC (дома UTC+1). Тесты сюда не пишут. До 2026-11-05 файл лежал в корне репозитория (`jarvis.log.jsonl`) вперемешку с логами тестов |
| `%APPDATA%\Jarvis\logs\jarvis.log` | Тот же лог текстом, локальное время, с трейсбеками |
| `%APPDATA%\Jarvis\debug\last_llm_request.json` | Последний запрос к модели (промпт, память, история, вызовы инструментов), только с `JARVIS_DUMP_LLM_REQUEST=1`. Разбор: `python -m jarvis.dev.llm_replay` |
| `%APPDATA%\Jarvis\memory\memory.db`, `collections.db` | Память и сохранённые списки. Тексты зашифрованы DPAPI, читаются только дома через `MemoryStore` / `CollectionStore` |

Сами реплики в лог не пишутся (приватность), только длина и решения роутера. Текст реплик, ушедших в модель, есть в дампе.

## 2. Цель: что значит «готово»

**v1.0** — это:

1. **Устанавливается как программа.** `Jarvis-Setup-1.0.0.exe`: ставится, запускается, удаляется; при первом запуске находит Ollama или предлагает её поставить и скачивает модель. Это фаза 7 из `BUILD.md`.
2. **Стабилен в ежедневной работе.** Неделя домашнего использования без падений и без «зависших» состояний; сон/пробуждение освобождают VRAM; после сбоя модуля голосовой цикл продолжает работать.
3. **Проверен регрессией.** Набор контрольных фраз ru/uk/en: автоматически на уровне роутера (работа) и вживую по чек-листу (дом), всё зелёное.
4. **Документация совпадает с кодом:** `SPEC.md`, `README.md`, `CHANGELOG.md`.
5. **Выпущен:** версия `1.0.0`, тег, релиз на GitHub.

Всё, что не входит в эти пять пунктов, идёт после v1.0 (раздел 4).

## 5. Бэклог

Найдено в живых сессиях 2026-11-03. Номера используются в этапах выше.

### P1 — заметно мешает (этап M1)

**B-P1-12. Голосовые команды отвечают по-английски. [Работа]**
Найдено при сборке регрессии (M3): когда команду выполняет шаблон (без модели), Jarvis читает вслух `output` инструмента как есть — по-английски и с внутренними подробностями («Reminder set for 30m from now (id: 3f2a…)»), даже если просили по-русски. Введено `ToolResult.spoken`: короткая фраза на языке запроса (`jarvis.core.phrases.say`), которую говорит голос, а `output` по-прежнему читает модель. Уже переведены: громкость, скриншот, блокировка, закрытие программы, таймеры, напоминания, заметки, медиаклавиши, окна и рабочие столы, буфер обмена, яркость и ночной режим, режим фокуса, питание, IP, скорость интернета, место на диске и очистка временных файлов, панели логов / дашборда / чата / истории буфера, диктовка, уведомления, режим «Ультра» (раньше сами отвечали на языке запроса: открытие, игры, погода, YouTube, время, калькулятор, конвертер, откат файлов). Числа с единицами — `phrases.quantity()` («120 гигабайт»). Осталось: файлы (`file_manager`), вкладки и закладки браузера, мышь, процессы и автозагрузка, загрузки и пакеты, сохранения игр, RSS, QR, хранилище паролей, проактивность, панели агента и исследований, протоколы и навыки. Ответы, где главное — данные, переводить шаблоном фразы, а не словарём.

### P2 — качество и техдолг (этапы M1–M2)

**B-P2-7. Jarvis часто переспрашивает. [Дом]**
«Повторите» при уверенности 0,42, 0,47, 0,50, 0,66 и 0,69; случай 0,69 — фраза из 45 символов. В одном случае само распознавание шло 7,8 с вместо обычных 0,7–0,9 с — выяснить почему. Посмотреть порог clarify в конфиге STT, учитывать длину фразы.

**B-P2-11. В 18:42 закончилась память. [Дом]**
В одну секунду: `MemoryError` в wake word (openwakeword, процесс Jarvis) и HTTP 500 от Ollama. На машине 32 ГБ; во время проверки была запущена игра (~5 ГБ). Выяснить, сколько памяти занимает Jarvis со временем (записывать RSS процесса в лог раз в минуту — `core/resource_monitor.py`), нет ли роста при фоновом чтении.

**B-P2-12. Приложение Ollama 39 тысяч раз пыталось запустить сервер. [Дом]**
`%LOCALAPPDATA%\Ollama\server.log`: с 07:15 каждую секунду «bind: Only one usage of each socket address» — сервер уже запущен другим способом (например, `start-jarvis.ps1` делает `ollama serve`), а приложение в трее тоже пытается его поднять. Оставить один способ запуска (или выключить автозапуск приложения Ollama, или не запускать `ollama serve` в скрипте, если приложение уже работает).

### P3 — потом (после v1.0)

**B-P3-5. Онлайн-интеграции с ключом не подключаются. [Работа]**
Найдено при M2-1: `plugin.auth` нигде не присваивается и `connect()` нигде не вызывается — `IntegrationRegistry.enable()` только помечает плагин включённым. Поэтому у плагинов с API-ключом (`news`, `github`, `hue`, `todoist`, …) `_api_key()` всегда `None`, и их инструменты отвечают «not connected». Вкладка «Integrations» сохраняет только `api_key`, а дополнительные поля из `auth_fields` (IP моста Hue, адрес Home Assistant, токен Trello) — нет, хотя `IntegrationAuth.get_field()` теперь есть. Нужно: передавать `IntegrationAuth` в реестр, при включении выставлять `plugin.auth` и вызывать `connect()`, в настройках — поля для всех `auth_fields`. Интеграции выключены по умолчанию, это после v1.0 (V-план).

**B-P3-8. Нет голосовой команды «усни» для самого Jarvis. [Работа] — нужно решение**
Найдено при сборке регрессии (M3): справка обещала «go to sleep» / «stop listening» (сон Jarvis) и «mute» / «unmute», но «go to sleep», «усни», «засни» → `power_control` (сон **компьютера**, с подтверждением), «mute» и «stop listening» → модель, у которой нет такого инструмента. Сон и тишина есть только в трее и на Ctrl+Shift+M; справка исправлена под это. По SPEC во сне выгружается и wake word, так что «разбудить фразой» нельзя — только из трея. Решить: (1) «Джарвис, усни» / «go to sleep» — сон Jarvis через `ModeCoordinator`, а сон компьютера — только «усыпи компьютер» / «спящий режим»; (2) «mute» / «замолчи на время» — режим MUTED; (3) оставить как есть.

**B-P3-7. «Стоп» ставит музыку на паузу, а не останавливает Jarvis. [Работа] — нужно решение**
Найдено при сборке регрессии (M3): «стоп» / «пауза» / укр. «зупини» → `media_control` (пауза плеера), а «хватит», «тихо», «досить», английское «stop» → остановка речи Jarvis (`_STOP_PATTERN` в `intent_router.py`). Если Jarvis говорит, а музыка не играет, «стоп» отправит клавишу паузы вместо того, чтобы его перебить. Варианты: (1) «стоп» — всегда остановка речи, пауза — только «пауза» / «поставь на паузу»; (2) «стоп» во время речи Jarvis — остановка, иначе — пауза. Сейчас в регрессии «стоп» не закреплён.

**B-P3-6. Голосовые шаблоны памяти и алиасов не подключены. [Работа] — нужно решение**
Найдено при сборке регрессии (M3): `remember_fact`, `search_memory`, `forget_fact`, `learn_app_alias` регистрируются, но их нет в каталоге (`jarvis/tools/catalogue.py`), поэтому их шаблоны никогда не работали — эти команды доходили только до модели. Включить их как есть нельзя: у первых трёх шаблоны не передают аргументы (`fact` / `query`), а «remember / запомни …» у `remember_fact` перехватит заметки и «запомни эту страницу»; шаблон `learn_app_alias` («запомни, что X это Y») поймает и «запомни, что Маша — это моя сестра» и сохранит её как программу; «запомни, что баттл — это стим» сейчас разбирается в цель «это стим». Предложение: (1) «что ты помнишь о X» / «what do you remember about X» → `search_memory` с аргументом; «что ты знаешь о X» оставить модели; (2) «забудь X из памяти» → `forget_fact` (с подтверждением); (3) `remember_fact` без шаблона — «запомни X» остаётся заметкой; (4) `learn_app_alias` — только если Y это известная программа / цель «открой», иначе отказ. Список исключений — `tests/tools/test_catalogue_completeness.py`.

**B-P3-1. «прохождение первой главы» неоднозначно. [Работа]**
«прохождение» и «пройти» не считаются одним словом. Словарь основ («прохожд/пройт», «получ/выполн»).

**B-P3-4. Другие `connect(lambda …self…)` в UI. [Работа]**
Та же схема, что уронила тесты в B-P2-15 (Qt держит слот, `gc` эту ссылку не видит, виджет без родителя не освобождается): `ui/command_palette.py:237`, `ui/settings/main_window.py:226`, `ui/settings/tabs/integrations.py:116,121`, `ui/commands_widget.py:289`. Пока виджеты с родителем, это безвредно; при случае заменить на методы или `partial` без `self`.

**B-P3-3. Срабатывания wake word у самого порога. [Дом]**
Оценки 0,44–0,47 при пороге 0,44 — проверить, ложные ли.

## 6. Проверка дома

Фразы для живой сессии; ожидаемое поведение — после стрелки. Сначала общий прогон R1–R14 (этап M3-3, проходится целиком перед релизом), затем пункты конкретных задач. Новые пункты добавляются сюда вместе с задачей, которую они проверяют. Что делать с результатом — см. «После сессии» в конце раздела.

### Сценарии R1–R14

Перед началом: Jarvis запущен через `start-jarvis.ps1`, Ollama работает, в трее зелёный значок. В каждом пункте, где ответ по-русски, проверить и украинский вариант хотя бы одной фразой.

- **R1. Язык.** «Привет, как дела?» → ответ по-русски; «Привіт, як справи?» → по-українськи; «What time is it?» → по-английски. «Говори по-украински» → «Переключився на українську, сер.», дальше ответы по-украински; «автоопределение языка» → снова по языку фразы.
- **R2. Открыть программу и сайт.** «Открой блокнот» → Блокнот открылся, «Открываю Блокнот, сэр.»; «открой ютуб» → YouTube в браузере; «открой стим в браузере» → сайт Steam; «відкрий калькулятор» → калькулятор.
- **R3. Закрыть.** «Закрой блокнот» → «Закрываю Блокнот, сэр.» и окно закрылось; «закрий калькулятор» → то же по-украински.
- **R4. Поиск и время.** «Найди рецепт борща» → Google с запросом «рецепт борща»; «который час» → время сразу, без паузы на модель; «какое сегодня число» → дата.
- **R5. Страница и список.** Открыть гайд по достижениям → «Запомни эту страницу» → уведомление о чтении, затем «Сохранил «…», пунктов: N»; «что осталось» → число и первые пункты; «отметь <пункт> как выполненный» → «Отметил…»; «что осталось» → на один меньше.
- **R6. Заметки.** «Запиши заметку купить хлеб» → «Записал, сэр: «купить хлеб».»; «открой заметки» → панель, в ней «купить хлеб» (без слова «заметку»); «закрой заметки». По-украински: «запиши нотатку купити молоко».
- **R7. Таймер.** «Поставь таймер на одну минуту» → «Таймер на 1 минуту, сэр.»; через минуту → «Таймер истёк, сэр.»; «поставь таймер на полчаса» → «Таймер на 30 минут, сэр.» → «какие таймеры» → «Активные таймеры: …» с оставшимся временем.
- **R8. Напоминание.** «Напомни через две минуты проверить чайник» → «Напомню через 2 минуты, сэр: проверить чайник.»; через две минуты → «Напоминаю, сэр: проверить чайник»; «напомни завтра в 10 позвонить» → «Напомню завтра в 10:00, сэр: позвонить.»; «какие у меня напоминания» → список; удалить тестовое («удали напоминание позвонить»).
- **R9. Громкость и медиа.** При играющей музыке: «громче», «тише», «выключи звук», «включи звук» → громкость меняется, короткие ответы по-русски; «пауза» → музыка на паузе; «следующий трек». «Стоп» сейчас = пауза музыки (B-P3-7).
- **R10. Сон и пробуждение.** Трей → «Sleep»: значок серый, на «Джарвис» не реагирует, `ollama ps` — модель выгружена, память процесса Jarvis заметно меньше (Диспетчер задач). Трей → «Wake»: через несколько секунд снова отвечает. Ctrl+Shift+M → «Mute», ещё раз → снова слушает. Голосом «усни» **не** говорить: сейчас это сон компьютера (B-P3-8).
- **R11. Перебивание.** «Расскажи подробно историю Рима» → во время ответа сказать «Джарвис» → речь обрывается, Jarvis слушает новую команду. С колонками (без наушников) может не сработать — записать, как было.
- **R12. Ошибка Ollama.** Закрыть Ollama (трей Ollama → Quit; если запущена `ollama serve` из `start-jarvis.ps1` — закрыть её окно) → «расскажи анекдот» → «Языковая модель не отвечает, сэр. Проверьте, запущена ли Оллама.»; команды по шаблонам («громче», «который час») при этом работают. Запустить Ollama → анекдот рассказывается.
- **R13. Подтверждение опасного действия.** «Удали файл test.txt на рабочем столе» (файл заранее создать) → запрос подтверждения → подтвердить → файла нет; «верни как было» → файл на месте. «Удали программу <что-то ненужное>» → подтверждение → отказаться → ничего не удалено.
- **R14. Микрофон.** В Настройки → Голос выбрать микрофон, затем выключить его (или выдернуть USB) и перезапустить Jarvis → уведомление «Microphone "…" not available; using "…"», Jarvis работает с другим. Выдернуть микрофон во время работы — записать, что произошло (поведение пока не задано).

### Пункты отдельных задач

- **Таймер и напоминание на языке запроса (B-P2-9).** «Поставь таймер на одну минуту» → через минуту по-русски: «Таймер истёк, сэр.» (или «Таймер «…» истёк, сэр!», если модель дала таймеру имя). «Постав таймер на півхвилини» → по-украински («Таймер спрацював, сер.»). «Напомни через две минуты купить молоко» → «Напоминаю, сэр: купить молоко». Английских «Timer … is done, sir!» быть не должно.
- **Погода (B-P1-9).** «Какая погода?» → по-русски, со шкалой: «Сейчас 7 градусов по Цельсию, пасмурно, сэр.»; «Яка погода?» → по-українськи. Сравнить с прогнозом за окном. В логе должна быть строка `weather: location from IP: <город>, ... (<широта>, <долгота>)` и `detected location saved to config`, а в `%APPDATA%\Jarvis\config.json` — `weather.unit = "celsius"` и заполненные `latitude` / `longitude`. Если город не тот (VPN, провайдер) — задать координаты в Настройки → Общие. Если строк `weather:` в логе нет совсем, значит, инструмент не вызывался и «86 градусов» модель придумала сама: записать в бэклог. Если есть `ipapi.co gave no location (reason: RateLimited)` — нужен другой способ определения места.
- **Повтор упавшей части страницы (B-P2-10).** Специально не воспроизвести (нужна ошибка 500 от Ollama); при следующем сохранении большой страницы посмотреть в логе: если есть `part N/M failed; retrying once in 15 s`, то за ней должен идти либо успешный разбор, либо `failed again; skipped`, а в объявлении — «Не прочитано частей страницы: 1 из 9, список может быть неполным».
- **Выход во время чтения страницы (B-P2-8).** «Запомни эту страницу» на большой странице, через 20–30 с — выход из трея. В логе: `shutdown: stopped reading <адрес>; the page is NOT saved`, после неё никаких `[page_extractor] ... part N/M`, Jarvis закрывается без задержки.
- **JSON-лог в папке данных (B-P2-2).** После запуска дома строки живой сессии пишутся в `%APPDATA%\Jarvis\logs\jarvis.log.jsonl`, каждая строка один раз (раньше каждая была дважды), а `jarvis.log.jsonl` в корне репозитория больше не растёт (старый файл можно удалить).
- **Искажённый глагол (B-P2-5).** Если STT напишет «Открый блокнот» / «Открою калькулятор» / «Закрою блокнот», команда должна выполниться сразу, без похода в модель: в логе роутер выбирает шаблон, `last_llm_request.json` не обновляется.
- **«Сэр» вместо «sir» (B-P2-13).** По-русски: «Скриншот», «Громче», «До свидания» — в конце звучит «сэр», а не искажённое английское слово; по-украински — «сер».
- **Прогресс сохранения страницы (B-P1-10).** «Запомни эту страницу» на большом гайде: всплывает уведомление «Читаю «…» в фоне. Скажу, когда сохраню.»; при наведении на значок в трее — «Читаю «…»: часть 3 из 9», номер растёт; «как там страница?» отвечает тем же; в конце — уведомление и голосом «Сохранил «…», пунктов: N». В логе — `[web_knowledge] reading <адрес>: part N/M`.
- **Гайды Steam (B-P1-11).** Гайд по Uncharted → «Запомни эту страницу» → 101 пункт (было 221), с описаниями «как получить» из гайда; Bleach — по-прежнему 36. В логе: `Steam guide for app <appid>`, `[steam] app <appid>: N official achievements`, `Steam app ...: N official achievements (the guide gave M items)`. **Разбор страницы статистики Steam написан вслепую** (из облака steamcommunity.com недоступен): если в логе `0 official achievements` или `unavailable`, сохранить страницу `https://steamcommunity.com/stats/<appid>/achievements/?l=russian` (Ctrl+S) и отдать Claude — поправить `parse_achievements`.
- **Запуск не из `.venv` (B-P2-6, M2-2).** Один раз запустить глобальным `python -m jarvis` из папки проекта: одно окно ошибки, в тексте — «Start it with: …\.venv\Scripts\python.exe -m jarvis (or start-jarvis.ps1)», и Jarvis **не** перезапускается ещё дважды (в логе `cannot start in this environment; not restarting`). Официальный запуск — `start-jarvis.ps1` или `.venv\Scripts\python.exe -m jarvis`; неотслеживаемые `run_jarvis.ps1` / `home_check*.ps1` в корне можно удалить.
- **Откат удаления и перезаписи (M2-4).** Попросить Jarvis удалить тестовый файл на рабочем столе («удали файл test.txt на рабочем столе», подтвердить) → файла нет; «верни как было» → «Вернул «test.txt» на место, сэр.» и файл снова на месте. Скопировать файл поверх существующего с тем же именем → «верни как было» → «Вернул прежнюю версию …». Копии лежат в `%APPDATA%\Jarvis\undo\` (не больше 20, не дольше недели).
- **Сбой модуля не глушит Jarvis (M2-3).** Специально сломать модуль сложно; проверить, что обычная работа не изменилась (wake word, ответы), и посмотреть в логе: строк `[module] … failed` быть не должно. Если они есть — после 5 сбоев wake word подряд должно прийти уведомление в трее «Wake word detection keeps failing and is switched off…» и голосом «Сэр, распознавание слова «Джарвис» постоянно сбоит, я его отключил…», а горячая клавиша — работать. Сбой распознавания речи в одном ходе → «Распознавание речи не сработало, сэр. Попробуйте ещё раз.» вместо общей ошибки.
- **Ответы команд на языке запроса (B-P1-12).** «Громче» → «Громче, сэр.»; «поставь таймер на пять минут» → «Таймер на 5 минут, сэр.»; «напомни через полчаса купить молоко» → «Напомню через 30 минут, сэр: купить молоко.» (без «id»); «напомни завтра в десять позвонить маме» → «Напомню завтра в 10:00, сэр: …»; «какие у меня напоминания» → список по-русски; «закрой блокнот» → «Закрываю Блокнот, сэр.»; «запиши заметку купить хлеб» → «Записал, сэр: «купить хлеб».» (в заметке нет слова «заметку»); «следующий трек», «сверни все окна», «яркость 50», «сколько места на диске», «какой у меня IP» — ответ по-русски; «наступний трек», «закрий блокнот» — по-украински (раньше эти фразы без і/ї/є/ґ считались русскими). Английских «Volume up» / «Timer … set» / «Disk space, sir» быть не должно.
- **Числа словами (M3).** «Поставь таймер на пять минут», «на полчаса», «напомни через час выключить плиту», «напомни через полтора часа …», «постав таймер на півхвилини» → сразу таймер / напоминание, без паузы на модель (в логе роутер выбирает `set_timer` / `remind_me`). «Напомни в восемь вечера купить хлеб» → «Напомню в 20:00, сэр: купить хлеб.»; «нагадай завтра о дев'ятій …» → на 9:00 завтра (`remind_me_at`).
- **Время и язык без модели (M3).** «Который час», «котра година», «какое сегодня число» → ответ сразу, без паузы на модель; «говори по-украински» / «speak english» → переключение голоса и распознавания сразу (в логе роутер выбирает шаблон `get_time` / `switch_language`, `last_llm_request.json` не обновляется).
